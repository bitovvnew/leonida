# LEONIDA · Xbox Edition for PC

Xbox Edition is the project’s working name for its planned Windows edition inspired by the Xbox version of Grand Theft Auto VI. The team’s aim is to give PC players more control over how they play and to document the process in public.

## Winter preview

December 22, 2026 is the planned project preview. The public repository currently ships an original, offline coastal driving scene. The native Windows build has a separate release milestone. Compatibility results will identify the build, hardware and route used for each capture.

LEONIDA is an independent fan project, unaffiliated with Rockstar Games, Take-Two Interactive or Microsoft.
